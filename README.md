# HỆ THỐNG ĐIỀU HÀNH & QUẢN TRỊ CHUYỂN ĐỔI SỐ 102 PHƯỜNG / XÃ TỈNH AN GIANG
### Nền tảng Giám sát, Điều phối Công việc & Hỗ trợ Hoạt động Tổ Công nghệ số cộng đồng (Tổ CNSCĐ)

---

## 🌟 Giới Thiệu
Hệ thống quản trị và điều hành chuyển đổi số toàn diện cho **102 đơn vị hành chính cấp xã** (14 Phường, 85 Xã, 3 Đặc khu) thuộc tỉnh An Giang. Ứng dụng hỗ trợ lãnh đạo cấp tỉnh, UBND cấp xã, các Tổ trưởng và Thành viên Tổ CNSCĐ theo dõi tiến độ, tiếp nhận và xử lý yêu cầu phản ánh của công dân, hỗ trợ số hóa cơ sở.

## 🚀 Các Tính Năng Nổi Bật

### 1. Trang Quản Lý Tổng Cấp Tỉnh (102 Phường / Xã)
- **Báo cáo & Thống kê toàn diện 102 Đơn vị:** Theo dõi tỷ lệ hoàn thành 6 bước nhiệm vụ số hóa, số việc hoàn thành, yêu cầu dân gửi theo từng đơn vị.
- **Biểu đồ Trụ cột Chuyển đổi số cấp xã:** Đánh giá 4 trụ cột DTI (Chính quyền số, Kinh tế số, Xã hội số, An toàn thông tin).
- **Tiến độ theo 5 nhóm đối tượng trọng tâm:** Hộ nghèo/chính sách, Hộ kinh doanh, Tiểu thương chợ truyền thống, Doanh nghiệp/HTX, Cán bộ/Thanh niên xung kích.
- **Top 5 đơn vị xuất sắc nhất tỉnh:** Xếp hạng thi đua chuyển đổi số theo thời gian thực.
- **Quản lý & Phê duyệt tài khoản cán bộ toàn tỉnh:** Phê duyệt, phân quyền (Super Admin, Lãnh đạo UBND, Tổ trưởng, Thành viên) cho toàn bộ cán bộ trên địa bàn tỉnh.
- **Xuất dữ liệu & In báo cáo cấp tỉnh:**
  - Xuất bảng dữ liệu Excel/CSV cho 102 đơn vị.
  - Xem trước và In Báo cáo chuẩn thể thức văn bản hành chính Việt Nam (A4) phục vụ hội nghị và chỉ đạo điều hành.

### 2. Trang Điều Hành Cơ Sở (Cấp Phường / Xã)
- **Quản lý Nhiệm vụ 6 Bước:** Quy trình số hóa 6 bước chuẩn hóa (Tiếp nhận -> Khảo sát -> Triển khai -> Nghiệm thu minh chứng link lưu trữ -> Bàn giao -> Báo cáo).
- **Tiếp nhận & Xử lý Yêu cầu Dân:** Hệ thống ticket tiếp nhận phản ánh, phân công thành viên phụ trách và theo dõi tiến độ giải quyết.
- **Hồ sơ Đối tượng số hóa:** Quản lý dữ liệu người dân, hộ kinh doanh, tiểu thương, doanh nghiệp trên địa bàn xã.
- **Báo cáo hoạt động Tổ CNSCĐ:** Báo cáo định kỳ (Tuần, Tháng, Quý, Năm, Tùy chỉnh), xuất Excel và In/Xuất PDF trực tiếp.

## 🛠️ Công Nghệ Sử Dụng
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React, Motion.
- **Backend / Storage:** Express, Firebase Firestore & Authentication, LocalStorage Sync.
- **Deployment:** Tối ưu hóa sẵn sàng triển khai trên Vercel, Netlify hoặc Docker.

## 💻 Cài Đặt & Khởi Chạy

```bash
# Cài đặt thư viện
npm install

# Khởi chạy môi trường phát triển (Port 3000)
npm run dev

# Kiểm tra cú pháp TypeScript
npm run lint

# Build bản phát hành cho Production
npm run build
```
